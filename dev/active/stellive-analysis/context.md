## 운영자가 정한 기준 (대화에서)
- **후원 금액은 생방 기준.** 다시보기 채팅은 금액이 항상 0 이다 → `collect/chzzk_live_chat.py`(`collect-live-chat`).
- **다시보기 채팅은 내용을 저장하지 않는다.** 고유 id(해시)를 가진 시청자가 방송 한 시간 동안 친 채팅 수를 합해 둔다
  (`collect/data/chat_user_hours.csv`, 생방은 `live_chat_user_hours.csv`).
- 버튜버는 **운영자가 확인해 명단(`collect/vtuber_roster.csv`)에 올린 사람만** 집계한다. 제목·태그로 잡은 후보는 참고.
- 결론 문장에 멤버 이름을 붙인 순위를 쓰지 않는다(표·차트에만).
- 막힌 사이트(아카라이브·펨코)는 우회하지 않는다. 운영자가 직접 저장해 올리면 같은 틀로 합친다.

## 알려진 한계
- 다시보기 채팅은 초당 ~20건(분당 ~1,240)까지만 저장돼 4기 데뷔 방송 채팅 수는 하한이다.
- 생방 후원 중 일부는 금액 0 으로 온다(원인 미확인 — 건수와 금액을 따로 둔다).
- 눈팅 시청자·유입 경로는 치지직이 공개하지 않는다.
