## 운영자가 정한 기준 (대화에서)
- 기간: 2026-10-25까지 올라온 영상. 조회수는 수집 시점(10/27).
- **유튜브 영상 조회수에서 노래는 뺀다.** 노래 = stel-database 노래 통계(`SONG_DATA`) 곡.
  커버 쇼츠·3D 라이브 커버·노래 모음(제목에 cover·커버·MV·Playlist·메들리)도 영상에서 빼고 노래 평균에도 넣지 않는다.
- 조회수는 **만 단위**로 말한다(예: 약 283만 회).
- 최고 조회수는 **쇼츠와 일반 영상을 따로**, 제목과 함께.
- 멤버마다 쇼츠 상위 5개 · 일반 영상 상위 5개 · 노래 상위 5곡.
- 비교는 **짧게, 필요한 것만**. 표는 평균 순으로 정렬.
- 칸나(졸업)·강지는 제외. 4기는 데뷔 직후라 표에서 제외.
- 순위표를 README 본문에 쓰지 않는다(저장소 CLAUDE.md 규칙) → 별도 문서 + README 링크로 운영자가 승인.
