# 프로젝트 3 · 치지직 방송 패턴

**기준 2026-10-18**  · 날짜별 축적

## 결론

방송이 가장 많이 시작되는 시간대는 **새벽 1시(KST)** 다. 심야 편성이 예외가 아니라 기본값이고, 주간 방송 시간이 긴 멤버와 방송을 자주 하는 멤버가 대체로 달라 '길게 적게' 와 '짧게 자주' 라는 두 전략이 공존한다. 게임 대 토크 비중도 멤버마다 갈려, 이 그룹에는 단일한 방송 공식이 없다.

---

## 데이터

- 데이터 소스: 치지직(Chzzk) 비공식 API — 다시보기(VOD replay) 3299건, 수집 2026-10-18
- 멤버 15명, 멤버당 최근 최대 300개 방송

## 한눈에

- **방송 시간과 방송 빈도**: 주간 방송 시간 상위 3명과 방송 빈도 상위 3명은 한 명도 겹치지 않는다.
- 주간 방송 시간: 중앙값 주 25시간 · 범위 주 6시간~주 42시간
- 회당 평균 방송: 중앙값 5.1시간 · 범위 0.9시간~7.6시간
- 방송 빈도: 중앙값 주 5.3회 · 범위 주 4.3회~주 14.0회
- 심야(0~5시) 시작 비율: 중앙값 51% · 범위 0%~81%
- 전체 방송이 가장 많이 시작되는 시간대: **1시** (KST)
