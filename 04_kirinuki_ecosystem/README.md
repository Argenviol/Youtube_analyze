# 프로젝트 4 · StelLive 키리누키(2차창작) 생태계 분석

스텔라이브 멤버들의 **팬 제작 클립(키리누키/切り抜き)** 생태계를 매핑합니다.
어떤 멤버가 2차창작으로 가장 많이 소비되는지, 어떤 팬채널이 생태계를 이끄는지,
팬채널이 특정 멤버 전문(오시)인지 종합형인지를 봅니다.

## 실행 방법

```bash
pip install -r ../requirements.txt
export YOUTUBE_API_KEY="발급받은_키"

python collect.py --per-query 40    # 멤버명+키리누키/클립/切り抜き 검색 -> data/clips.csv
python analyze.py                   # SQL/차트/리포트/사이트 데이터
python build_site.py                # site/index.html
```

## 방법론 & 필터

1. 멤버별로 `{멤버명} 키리누키`, `{멤버명} 클립`, `{멤버명} 切り抜き` 검색.
2. **공식 채널(멤버 본인·그룹 공식) 제외** → 순수 2차창작만.
3. 제목 또는 채널명에 클립 토큰(`키리누키|클립|切り抜き|kirinuki|clip`)이 있어야 인정
   (무관한 대형 쇼츠·커버 등 검색 노이즈 제거).
4. 클립을 만든 채널을 집계해 **멤버별 관심도**와 **팬채널별 규모/전문성**을 계산.

> 유튜브 검색 상위 표본 기반이라 생태계 전수가 아닌 **대표 표본**입니다. 토큰이 없는 클립은
> 제외되므로 실제 규모는 더 큽니다.

## 주요 결과 (수집 시점 스냅샷)

- **팬 클립 조회 1위**: 텐코 시부키(약 4.2M) — 클립 수는 중간이나 조회 효율 최상위.
- **최다 창작 관심**: 아야츠노 유니 — 19개 팬채널이 클립 제작(가장 넓은 팬 창작층).
- **최대 키리누키 채널**: 서트 클립(Surt Clip) — 텐코 시부키 주력, 총 2.6M.
- **생태계 구조**: 팬채널 대다수(49/74)가 **한 멤버 전문(오시 채널)**, 소수만 다멤버 종합형.
