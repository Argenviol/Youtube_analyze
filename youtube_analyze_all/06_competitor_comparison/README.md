# 06 · 경쟁사 비교 (데뷔 코호트 매칭)

**질문** — 스텔라이브는 홀로라이브·이세계아이돌과 비교해 어디에 서 있는가 — **같은 시기에 데뷔한 기수끼리.**

- 데이터: YouTube Data API — 세 그룹 42채널의 채널 지표 + 최근 30개 영상
- 갱신: daily

## 실행

```bash
export YOUTUBE_API_KEY=...
python collect.py --recent 30
python analyze.py
python build_site.py
```

## 왜 코호트로 묶는가

구독자는 거의 줄지 않는 **누적 지표**라 두 채널의 차이는 "누가 잘했나"보다 "누가 오래 했나"를 먼저 잰다.
이전 판은 홀로라이브 쪽을 유명한 6명으로 골랐는데 전원 2019~2020년 데뷔였고, 스텔라이브(2023~2025년 데뷔)와의
"구독자 10배 차이"는 대부분 4~6년 먼저 시작했다는 뜻이었다. 인지도로 고른 표본은 생존 편향이기도 하다.
그래서 **표본은 기수 전원**, **비교는 같은 코호트 안에서만** 한다.

| 코호트 | StelLive | 홀로라이브 | 이세계아이돌 |
|---|---|---|---|
| 2021–2022 | — | JP 6기 holoX · ID 3기 | 1기 전원 |
| 2023 | 1기 MYSTIC · 2기 UNIVERSE | EN Advent · DEV_IS ReGLOSS | — |
| 2024 | 3기 CLICHE | EN Justice · DEV_IS FLOW GLOW | — |
| 2025 | 사키하네 후야 | — | — |

이세계아이돌은 스텔라이브보다 1년 반 먼저 데뷔해 같은 코호트가 없다 — 억지로 붙이지 않고 같은 시기 홀로라이브
기수와 짝짓는다. 2025 코호트는 비교군이 없어 "비교군 없음"으로 둔다. FUWAMOCO 는 두 명이 채널 하나라 1행.
로스터·데뷔일 정본은 `common/config.py` 의 `COMPETITOR_ROSTER`·`DEBUTS`, 채널 ID 는 og:title 로 확인한 값.

## 지표를 읽는 법

| 지표 | 데뷔 시기 영향 | 쓰는 법 |
|---|---|---|
| 구독자 | 매우 큼(누적) | 같은 코호트 안에서만 |
| 월평균 구독자 획득(구독자 ÷ 경과 개월) | 중간 | 코호트가 달라도 속도 비교 가능. 데뷔 직후 급증이 섞여 신생에 유리 — 보조 지표 |
| 최근 영상 평균 조회수 | 작음 | 코호트 간 비교 가능 |
| 참여율 · 도달 효율 | 가장 작음 | 코호트 간 비교에 가장 안전. 조회수 1,000 미만 영상은 제외(업로드 직후 비율이 튄다) |
