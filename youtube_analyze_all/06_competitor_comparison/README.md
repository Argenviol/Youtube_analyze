# 프로젝트 6 · 경쟁사 비교 (데뷔 코호트 매칭)

**StelLive vs 홀로라이브(Hololive) vs 이세계아이돌(이세돌)** 을
**데뷔 시기가 겹치는 기수끼리** 비교한다.

## 왜 코호트로 묶는가

구독자는 매일 조금씩 늘고 거의 줄지 않는 **누적 지표**다. 그래서 두 채널의 구독자
차이는 "누가 더 잘했나"보다 "누가 더 오래 했나"를 먼저 잰다.

이전 버전은 홀로라이브 쪽 표본을 유명한 6명(우사다 페코라·가우르 구라·호쇼 마린 ·
모리 캘리오프·모모스즈 네네·이누가미 코로네)으로 골랐다. 이들은 2019~2020년 데뷔고
StelLive 는 2023~2025년 데뷔다. **평균 구독자 10배 차이**라는 결과는 대부분
4~6년 먼저 시작했다는 사실을 다시 말한 것에 가깝다. 게다가 표본을 인지도로 고르는
순간 그 표본은 생존편향이 된다 — 비슷한 시기에 데뷔했지만 크지 못한 채널은 애초에
후보에 오르지 않는다.

그래서 두 가지를 바꿨다.

1. **표본을 기수 전원으로.** 개인 인지도로 고르지 않는다.
2. **같은 코호트 안에서만 그룹을 비교.** 코호트가 다르면 같은 표에 올리지 않는다.

## 비교 구조

| 코호트 | StelLive | 홀로라이브 | 이세계아이돌 |
|---|---|---|---|
| 2021-2022 데뷔 | — | JP 6기 holoX(2021-11) · ID 3기(2022-03) | 1기 전원(2021-12) |
| 2023 데뷔 | 1기 MYSTIC(2023-01) · 2기 UNIVERSE(2023-06) | EN Advent(2023-07) · DEV_IS ReGLOSS(2023-09) | — |
| 2024 데뷔 | 3기 CLICHE(2024-05) | EN Justice(2024-06) · DEV_IS FLOW GLOW(2024-11) | — |
| 2025 데뷔 | 사키하네 후야(2025-09) | — | — |

- 이세계아이돌은 StelLive 보다 1년 반 먼저 데뷔해 StelLive 와 같은 코호트에 들어가지
  않는다. 억지로 붙이지 않고 **같은 시기 데뷔한 홀로라이브 기수와 짝지어** 본다.
- 2025 코호트는 비교 상대가 없다. 그룹 비교를 하지 않고 "비교군 없음"으로 남긴다.
- 후와와·모코코(FUWAMOCO)는 두 명이 채널 하나를 공유해 1행으로 센다.

모든 채널 ID 는 `youtube.com/channel/<id>` 응답의 og:title 로 실채널임을 확인했다
(핸들 추측 아님). 로스터 정본은 `common/config.py` 의 `COMPETITOR_ROSTER`,
데뷔일 정본은 같은 파일의 `DEBUTS` 다.

## 실행 방법

```bash
pip install -r ../requirements.txt
export YOUTUBE_API_KEY="발급받은_키"

python collect.py --recent 30    # 42채널 -> data/
python analyze.py                # SQL/차트/리포트/사이트 데이터
python build_site.py             # site/index.html
```

## 지표를 읽는 법

| 지표 | 데뷔 시기 영향 | 쓰는 법 |
|---|---|---|
| 구독자 | **매우 큼**(누적) | 같은 코호트 안에서만 비교 |
| 월평균 구독자 획득 (구독자÷경과개월) | 중간 | 코호트가 달라도 속도 비교 가능. 단 데뷔 직후 급증 구간이 섞여 신생 채널에 유리 — 보조 지표 |
| 최근 영상 평균 조회수 | 작음 | 코호트 간 비교 가능 |
| 참여율 · 도달 효율 | **가장 작음**(최근 영상 기준) | 코호트 간 비교에 가장 안전 |

참여율은 조회수 1,000 미만 영상을 제외하고 계산한다. 업로드 직후 영상은 좋아요·댓글이
먼저 붙고 조회수가 늦게 반영돼서, 넣으면 평균이 몇천 %로 튄다.

## 축적 데이터에 대한 주의

`data/history.csv` 는 2026-08 부터 날짜별로 쌓여 있는데, 2026-09-18 에 표본이 바뀌었다
(`_meta.json` 의 `method_changed_at`). 이전 표본에 있던 멤버(페코라·구라 등)의 행은
그대로 남아 있지만 그 날짜 이후로는 갱신되지 않는다. **멤버 개인의 추세는 경계를
넘어도 유효하고, 그룹 평균은 경계를 넘어 비교하면 안 된다.**
