## 인기 방송 카테고리 TOP 10

## 시작 시간대별 방송 수

```sql
SELECT CAST(substr(start_kst,12,2) AS INT) AS 시작시,
       COUNT(*) AS 방송수
FROM streams GROUP BY 시작시 ORDER BY 방송수 DESC LIMIT 8;
```
