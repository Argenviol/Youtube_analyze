# 프로젝트 3 · StelLive 치지직 방송 패턴 분석

- 데이터 소스: 치지직(Chzzk) 비공식 API — 다시보기(VOD replay) 2997건, 수집 2026-10-22
- 멤버 10명(방송이 10회 미만인 4명(시즈키 토아, 코가네 랑, 토키노 메리, 하나요 히요리)은 집계에서 제외), 멤버당 최근 최대 300개 방송
- 방송 시각은 **시작 시각**(다시보기 게시 시각 − 방송 길이)이다. 2026-10-19 전까지는 게시 시각(=방송 종료)을
  시작으로 써서 시작 시각·심야 비율이 방송 길이만큼 늦게 잡혀 있었다 — 그 전 `history.csv` 의 `night_share` 와 비교하지 말 것.

## 핵심 요약
- **방송 시간과 방송 빈도**: 주간 방송 시간 상위 3명과 방송 빈도 상위 3명이 같다.
- 주간 방송 시간: 중앙값 주 32시간 · 범위 주 23시간~주 42시간
- 회당 평균 방송: 중앙값 5.8시간 · 범위 4.9시간~7.7시간
- 방송 빈도: 중앙값 주 5.2회 · 범위 주 4.3회~주 6.1회
- 심야(0~5시) 시작 비율: 중앙값 2% · 범위 0%~9%
- 전체 방송이 가장 많이 시작되는 시간대: **18시** (KST)
