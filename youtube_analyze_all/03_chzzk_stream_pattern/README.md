# 03 · 치지직 방송 패턴

**질문** — 멤버들은 언제, 얼마나 길게, 무엇을(게임/토크) 방송하는가. 유튜브가 아니라 **실제 라이브** 관점.

- 데이터: 치지직 비공식 공개 API(`api.chzzk.naver.com`) — 채널 정보 + 다시보기(`videoType == REPLAY`) 목록. API 키 불필요
- 대상: 방송 10회 이상 멤버(`MIN_STREAMS`) — 그 미만은 주당 환산이 성립하지 않아 집계에서 뺀다
- 갱신: daily

## 실행

```bash
python collect.py --max 300     # 멤버당 최근 최대 300개 VOD → data/
python analyze.py
python build_site.py            # 요일×시각 히트맵 포함
```

## 지표 정의

| 지표 | 정의 |
|---|---|
| 방송 시작 시각 | **다시보기 게시 시각 − 방송 길이**(`common/chzzk.vod_start`). 게시 시각은 방송 **종료** 시각이다 |
| 주당 방송 횟수 · 시간 | 수집된 방송의 실제 기간(첫~마지막)으로 환산 |
| 심야 비중 | 시작이 0~5시인 비율 |
| 게임 비중 · 주력 카테고리 | `categoryType == GAME` 비율 · 가장 자주 방송한 카테고리 |

시간은 모두 KST. 채널 ID 는 `common/config.py` 의 `CHZZK_IDS`.

## 산출물

| `data/history.csv` | 날짜별 축적 |

## 읽는 법 · 한계

- 방송은 대부분 오후~저녁에 시작해 자정 무렵 끝난다. 0~5시 시작은 멤버별 한 자릿수 %다.
- **2026-10-19 전까지는 게시 시각을 시작으로 잘못 썼다.** 그래서 "심야형 78%", "새벽 1시 시작이 피크"로 읽혔다
  — 종료 시각을 시작으로 센 결과였다(08 로 관측한 방송 460회 중 80% 가 게시 = 관측 종료 ±20분). 그 이전
  `history.csv` 의 `night_share` 와 비교하지 않는다.
- 게임 비중은 멤버마다 크게 갈리고, 주당 시간이 긴 멤버와 자주 하는 멤버가 대체로 달라 단일한 방송 공식은 없다.
  멤버별 수치는 `REPORT.md`·차트에 있다.
