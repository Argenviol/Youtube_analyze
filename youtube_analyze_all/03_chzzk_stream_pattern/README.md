# 프로젝트 3 · StelLive 치지직 방송 패턴 분석

스텔라이브 멤버들의 **치지직(Chzzk) 다시보기(VOD replay)** 데이터를 모아 방송 빈도·길이·
시작 시간대·카테고리(게임/토크) 패턴을 분석합니다. 유튜브가 아닌 **실제 라이브 방송** 관점의 분석입니다.

## 실행 방법

```bash
pip install -r ../requirements.txt   # API 키 불필요 (치지직 공개 엔드포인트)
python collect.py --max 250          # 멤버당 최근 최대 250개 방송 -> data/
python analyze.py                    # SQL/차트/리포트/사이트 데이터
python build_site.py                 # site/index.html (히트맵 포함)
```

## 데이터 소스

치지직 비공식 공개 API(`api.chzzk.naver.com`)의 채널 정보 + 다시보기 목록.
`videoType == REPLAY`(생방송 다시보기)만 사용해 실제 방송만 집계합니다. 시간은 모두 KST.
멤버 채널 ID는 `common/config.py`의 `CHZZK_IDS`에 검증된 값으로 저장돼 있습니다.

## 지표 정의

- **주간 방송 횟수 / 시간** = 수집된 방송의 실제 기간(첫~마지막 방송)으로 환산한 주당 값.
- **방송 시작 시각** = 다시보기 게시 시각 − 방송 길이. 치지직 다시보기는 방송이 **끝난 뒤** 올라오므로 게시 시각은
  종료 시각이다(08 로 관측한 방송 460회 중 80% 가 관측 종료 ±20분 안). 2026-10-19 전까지는 게시 시각을 시작으로
  잘못 써서 시작 시각·심야 비중이 방송 길이만큼 늦게 잡혔다 — 그 전 `data/history.csv` 의 `night_share` 와 비교하지 말 것.
- **심야 비중** = 방송 시작 시각이 0~5시인 비율.
- 방송이 10회(`MIN_STREAMS`) 미만인 멤버(데뷔 직후)는 주당 환산이 성립하지 않아 집계에서 뺀다.
- **게임 비중** = `categoryType == GAME` 비율(나머지는 토크/기타).
- **주력 카테고리** = 가장 자주 방송한 카테고리 값.

## 주요 결과 (수집 시점 스냅샷)

- **방송 시간 최다**: 아라하시 타비 — 주 약 41.6시간(회당 평균 7.6h).
- **시작은 오후~저녁**: 방송의 약 4분의 3이 15~20시에 시작하고(가장 많은 건 18시), 대개 자정 무렵에 끝난다. 0~5시에 시작하는 방송은 멤버별 1~9%뿐이다.
  (예전 판의 "심야형 78%", "새벽 1시 시작이 피크"는 방송 **종료** 시각을 시작으로 잘못 센 결과였다.)
- **최고 게임형**: 아오쿠모 린 — 89%가 게임 방송(주력 마인크래프트).
- 대부분 멤버가 주력을 `talk`(저챗)로 두되, 게임 비중에서 성향이 크게 갈립니다.
