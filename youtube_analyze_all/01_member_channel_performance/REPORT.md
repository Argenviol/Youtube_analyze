- 데이터 소스: YouTube Data API v3 (수집 2026-08-30)
- 대상: StelLive 탤런트 10명, 채널당 최근 50개 영상
- 총 550개 영상 지표 집계

## 핵심 요약
- **최다 구독자(탤런트)**: 아야츠노 유니 — 359,000명
- **도달 효율 1위**(평균조회수/구독자): 유즈하 리코 — 143%
- **가장 부지런한 업로더**: 텐코 시부키 — 주 6.5회
- **참여율 1위**(좋아요+댓글/조회수): 네네코 마시로 — 4.8%

## 상관관계 (탤런트 10명)
| 관계 | 상관계수 r |
|------|-----------|
| 구독자 ↔ 최근 평균 조회수 | 0.337 |
| 업로드 빈도 ↔ 구독자 | -0.033 |
| 업로드 빈도 ↔ 평균 조회수 | 0.788 |
| 참여율 ↔ 구독자 | -0.745 |
| 도달 효율 ↔ 구독자 | -0.356 |

> 해석 힌트: 구독자와 평균 조회수의 상관이 높으면 "구독자 규모가 조회수를 견인",
> 도달 효율↔구독자 상관이 음수면 "소규모 채널일수록 구독자 대비 조회수가 높은"
