# API 키 발급 가이드

이 포트폴리오를 끝까지 돌리는 데 필요한 키는 **2개(필수) + 1개(선택)** 입니다.
전부 무료이고 결제수단 등록도 필요 없습니다.

---

## 1. YouTube Data API v3 — 필수

프로젝트 1·2·4·5·6 갱신에 필요합니다. **이게 없으면 기존 7개 중 5개를 갱신할 수 없습니다.**

### 발급 절차

1. **https://console.cloud.google.com/** 접속 (Google 계정 로그인)

2. **프로젝트 생성**
   - 상단 좌측 프로젝트 선택 드롭다운 → `새 프로젝트`
   - 이름: 아무거나 (예: `stellive-analytics`)
   - `만들기` → 생성까지 10~20초, 완료되면 그 프로젝트로 전환

3. **YouTube Data API v3 사용 설정**
   - 좌측 메뉴 `API 및 서비스` → `라이브러리`
   - 검색창에 `YouTube Data API v3` 입력 → 클릭 → **`사용` 버튼 클릭**
   - ⚠ 이 단계를 건너뛰면 키를 만들어도 403이 납니다.

4. **API 키 생성**
   - `API 및 서비스` → `사용자 인증 정보`
   - 상단 `+ 사용자 인증 정보 만들기` → **`API 키`**
   - `AIza...`로 시작하는 39자 문자열이 뜹니다. **복사해두세요.**

5. **키 제한 (선택이지만 권장)**
   - 생성 직후 뜨는 `키 제한` 또는 목록에서 키 클릭
   - `API 제한사항` → `키 제한` → `YouTube Data API v3`만 체크 → `저장`
   - 키가 유출돼도 다른 API에 쓰이지 않습니다.

### 알아둬야 할 쿼터

| 항목 | 한도 |
|---|---|
| 일반 엔드포인트 합산 | **10,000 units/일** |
| `search.list` 호출 | **100회/일** (별도 카운트) |

`search.list`는 **1회에 100 units**를 먹습니다. 프로젝트 2(커버곡)와 4(키리누키)가
검색을 쓰므로, **두 프로젝트를 같은 날 갱신하면 쿼터가 빠듯할 수 있습니다.**
갱신은 날짜를 나눠 돌리는 걸 권합니다. 쿼터는 **태평양 시간 자정(한국시간 오후 4~5시)** 에
초기화됩니다.

결제 계정 연결은 **필요 없습니다.** 무료 쿼터만으로 충분합니다.

## 2. Open DART — 필수

프로젝트 9(재무 분석)에 필요합니다. 팬덤 지표를 실제 매출과 연결하는 유일한 축입니다.

### 발급 절차

1. **https://opendart.fss.or.kr/** 접속

2. 상단 `인증키 신청/관리` → **`인증키 신청`**
   (직링크: https://opendart.fss.or.kr/uss/umt/EgovMberInsertView.do)

3. **개인 회원**으로 신청하세요. 입력 항목:
   - 이메일 (중복확인 필요)
   - 비밀번호 (8~14자, 영문+숫자+특수문자)
   - 이름, 휴대폰
   - **API 사용 환경**: `웹` 선택
   - **API 사용 목적**: 예) `개인 포트폴리오용 기업 재무데이터 분석`
   - **확인 URL**: 개인 프로젝트면 GitHub 저장소 주소나 개인 블로그 주소를 넣으면 됩니다.
     없으면 `http://localhost` 로도 통과합니다.

4. 이메일 인증 후 **즉시 발급**됩니다. (법인 회원은 사업자등록증 첨부 + 1~2 영업일 심사라
   개인으로 하는 게 훨씬 빠릅니다.)

5. 발급된 40자 인증키를 `인증키 신청/관리` → `오픈API 이용현황`에서 언제든 확인 가능합니다.

## 키 설정 방법 (Windows)

발급받은 키를 **사용자 환경변수**로 넣으면 모든 스크립트가 자동으로 읽습니다.

PowerShell에서 (한 번만 실행하면 영구 적용):

```bash
setx YOUTUBE_API_KEY "여기에_발급받은_키"
```

```bash
setx DART_API_KEY "여기에_발급받은_키"
```

⚠ `setx`는 **새로 여는 터미널부터** 적용됩니다. 실행 후 터미널을 다시 열어야 합니다.

확인:

```bash
echo $env:YOUTUBE_API_KEY
```

### 대안: .env 파일

터미널을 다시 여는 게 번거로우면 저장소 루트에 `.env` 파일을 만들어도 됩니다.
`.gitignore`에 이미 등록돼 있어 커밋되지 않습니다.

```
YOUTUBE_API_KEY=여기에_키
DART_API_KEY=여기에_키
```

## 키 외에 필요한 것

### 수집 데몬이 도는 동안 PC가 켜져 있어야 합니다

프로젝트 8(동시시청자)은 소급 수집이 불가능해서 **PC가 꺼져 있는 동안의 데이터는 영영
비어 있게 됩니다.** 방송이 주로 저녁~새벽에 몰리므로, 최소 며칠은 PC를 켜두거나
절전 모드를 꺼두는 게 좋습니다.

- 절전 해제: `설정 → 시스템 → 전원 및 배터리 → 화면 및 절전` 에서 절전을 `안 함`으로
- 터미널을 닫아도 계속 돌게 하려면 Windows 작업 스케줄러 등록이 필요합니다
  (시스템 설정 변경이라 원하시면 등록해 드립니다)

### 팬 커머스(프로젝트 11) 분석 대상 선정

팬딩에는 공개 크리에이터가 많은데, **어떤 층을 표본으로 삼을지**에 따라 결론이 달라집니다.
따로 지정하지 않으시면 버추얼/스트리머 카테고리 상위 공개 페이지를 기준으로 잡겠습니다.

### 추가 패키지

프로젝트 10(호요버스)에서 Google Trends를 쓰므로 하나만 더 설치하면 됩니다.
제가 진행하면서 자동으로 설치하겠습니다.

```bash
pip install pytrends
```
