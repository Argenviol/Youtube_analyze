# 04 · 키리누키(2차창작) 생태계

**질문** — 팬 제작 클립(키리누키·切り抜き)은 누구를 가장 많이 다루고, 어떤 팬채널이 생태계를 끌고 가며,
그 채널은 한 멤버 전문(오시)인가 종합형인가.

- 데이터: YouTube 검색 — 멤버별 `{이름} 키리누키` · `{이름} 클립` · `{이름} 切り抜き`
- 갱신: weekly. 직전 수집이 6일 안쪽이면 검색하지 않는다(`FRESH_DAYS`, 검색 쿼터 절약)

## 실행

```bash
export YOUTUBE_API_KEY=...
python collect.py --per-query 40 [--force]   # --force: 6일 안쪽이어도 다시 검색
python analyze.py
python build_site.py
```

## 방법

1. 멤버별 3개 쿼리로 검색.
2. 공식 채널(멤버 본인·그룹 공식) 제외 → 순수 2차창작만.
3. 제목 또는 채널명에 클립 토큰(`키리누키|클립|切り抜き|kirinuki|clip`)이 있어야 인정(검색 노이즈 제거).
4. 제작 채널을 집계해 멤버별 관심도와 팬채널별 규모·전문성을 계산.

## 산출물

| 경로 | 내용 |
|---|---|
| `data/clips.csv` | 클립별(제작 채널·조회·좋아요) |
| `data/member_ecosystem.csv` · `channel_ecosystem.csv` | 멤버별(클립 수·총조회·팬채널 수) · 팬채널별(구독자·클립 수·다루는 멤버 수·주력) |
| `sql/` · `charts/`(6종) · `site/` · `REPORT.md` | 공통 산출물 |

## 읽는 법 · 한계

- **표본이지 전수가 아니다.** 검색 상위에서 모은 것이라 인기 클립 쪽으로 치우치고, 토큰이 없는 클립은 빠진다.
  멤버별 클립 수는 생산량이 아니라 검색이 건진 양이다 — 비율은 상한으로 읽는다.
- 멤버별 팬 클립 총 조회수는 수십 배까지 벌어지며, 소수 대형 클립 채널이 누구를 다루느냐에 크게 좌우된다.
- 팬채널 대다수가 한 멤버 전문이고 소수만 종합형이다. 채널 수·멤버별 수치는 `REPORT.md`.
- 12 에서는 이 표본으로 "무엇이 클립이 되나"를 본다 — 기획 이벤트가 아니라 방송 중 우연한 순간이 대부분이다.
