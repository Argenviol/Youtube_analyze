# 프로젝트 12 · 이벤트 임팩트 분석

대규모 합방·커버곡 발매·콘서트 같은 **사건**을 찾아 기억하고, 그 전후로 팔로워·구독자·
동시시청자가 어떻게 움직였는지 붙인다.

```bash
python 12_event_impact/collect.py     # 이벤트 감지 + append-only 기억
python 12_event_impact/analyze.py     # 전후 변화 측정 + 차트 + REPORT.md
python 12_event_impact/build_site.py  # 대시보드
```

## 신규 API 호출이 없다

01·02·03·08이 이미 모아 둔 데이터를 다시 읽을 뿐이다. YouTube 쿼터를 한 unit 도 쓰지

(`refresh.py` 의 `daily` 맨 뒤).

## 합방을 어떻게 찾아내나

치지직 VOD 의 제목과 카테고리에 이미 답이 들어 있다. 두 신호를 쓴다.

| 신호 | 규칙 | 잡히는 것 |
|---|---|---|
| 카테고리 동시성 | 같은 날 같은 게임을 4명 이상이 방송 | 마인크래프트 서버, 팰월드, 월드컵 시청 |
| 제목 토큰 공유 | 같은 날 4명 이상의 제목에 같은 단어 | 봉켓몬, 갈틱폰, 3주년, 모라하지마 |
| 신의상 (제목+조회수) | 제목에 '신의상' + 평소 조회수의 2배 이상 | 여름 휴가 릴레이, 가을 릴레이 |

`talk` 은 치지직의 기본 카테고리라 "그날 다들 잡담했다"만으로도 8명이 걸린다. 카테고리
신호에서 제외한다.

제목 신호의 진짜 문제는 '오늘'·'같이'·'게임' 같은 흔한 말이다. 불용어 목록을 손으로 쓰면
계속 새는 단어가 생기므로, **토큰이 전체 방송일 중 몇 %에 등장하는지(문서빈도)를 세서
10%를 넘으면 고유명사가 아닌 것으로 본다.** 실측 481일 기준 이 규칙이 '오늘·같이·게임'을
전부 떨어뜨리고 '봉켓몬·갈틱폰·모라하지마'만 남겼다.

한 이벤트가 여러 신호로 동시에 걸리면 합친다. 판정은 **날짜 집합의 자카드 유사도**로
한다 — 기간이 겹치는지만 보면 6/25 하루짜리 월드컵 시청이 6/23~7/2 마인크래프트 서버
안에 들어간다는 이유로 한 건이 돼버린다(실제로 그렇게 합쳐졌다).

## 무엇을 잴 수 있고 무엇을 못 재나

| 지표 | 측정 가능 구간 | 왜 |
|---|---|---|
| VOD 조회수 배수 | 2025-04~ (소급 가능) | 치지직 VOD readCount 는 과거분이 남아 있다 |
| 치지직 팔로워 | 2026-08-12~ | 일일 축적(history.csv) 시작일 |
| 유튜브 구독자 | 2026-08-12~ | 위와 같음. 1,000 단위 반올림이라 7일 창으로만 |
| 동시시청자 피크 | 2026-08-12~ | 08 스냅샷 시작일 (소급 불가) |
| **수익** | **불가** | 치지직·유튜브 모두 비공개 |

수집 이전 이벤트의 전후 변화는 **계산하지 않는다.** 0% 가 아니라 측정 불가이고, 둘은 다르다.

이벤트 후 5일이 지나야 전후 비교를 낸다. 창이 안 찬 상태로 계산하면 관측 부족이 지표
폭락으로 둔갑한다 — 실제로 8/27 이벤트가 이틀치 데이터만으로 "구독자 -100%"를 냈다.

## 수동 등록

자동 감지는 치지직 방송이 있어야 한다. 유튜브 전용 합방·오프라인 행사·콘서트·오리지널곡
발매는 흔적이 없으므로 `data/events_manual.csv` 에 적는다. 같은 날 같은 종류의 자동 항목이
있으면 수동 쪽이 이긴다 — 사람이 붙인 이름이 토큰('봉켓몬')보다 정확하다.

```csv
date,end_date,type,title,members,note,source
2026-07-11,2026-07-12,콘서트,아카네 리제 첫 단독 콘서트,아카네 리제,,수동
```

`members` 는 `|` 로 구분한다. `type` 은 합방·커버곡·콘서트·오리지널곡·오프라인.

## 신의상 공개는 왜 조회수까지 보나

제목만 보면 안 된다. '신의상'이 들어간 방송의 절반은 예고("내일 8시에 공개")·대기방·
남의 공개 시청이다. 봉누도의 설명회와 같은 문제다.

실제 공개는 **조회수로 갈린다.** 실측 31건에서 예고·대기방은 평소 대비 0.29~1.60배에
몰려 있고 실제 공개는 2.01배부터 시작한다. 그 사이가 비어 있어서 2.0을 경계로 쓴다.
가까운 날짜(3일 이내)의 공개는 릴레이 하나로 묶고, 제목에서 두 명 이상이 공유한 말을
뽑아 이름을 만든다('스텔 여름 휴가 신의상 릴레이 공개 (8명)').

⚠ 신의상은 **합방의 연속일 기준을 적용하지 않는다.** 혼자 하루 공개해도 그 자체가
이벤트다. 연속 며칠 기준은 합방에만 쓴다.
