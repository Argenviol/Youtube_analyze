# 12 · 이벤트 임팩트

**질문** — 무슨 **사건**(합방·신의상·커버곡·오리지널곡·콘서트·생일·데뷔)이 지표를 움직였는가. 다른 프로젝트는
"지금 얼마인가"를 답하고, 이 프로젝트는 "무슨 일이 있어서 그렇게 됐는가"를 답한다.

- 데이터: **신규 API 호출 없음.** 01·02·03·08 등이 이미 모은 데이터를 다시 읽는다 — 그래서 `daily` 의 맨 뒤에서 돈다
- 갱신: daily. 리포트 산문의 숫자는 전부 데이터에서 계산한다(손으로 적은 수치 없음)

## 실행

```bash
python collect.py     # 이벤트 감지 + append-only 기억(events_seen.csv)
python analyze.py     # 전후 변화·배수 측정 → charts/ sql/ REPORT.md site/data.json
python build_site.py
```

## 이벤트를 찾는 법

| 종류 | 신호 | 비고 |
|---|---|---|
| 합방 | 치지직 VOD 의 **카테고리 동시성**(같은 날 같은 게임 4명 이상) 또는 **제목 토큰 공유**(같은 날 4명 이상 제목에 같은 단어), **연속 2일 이상**만 | `talk` 은 기본 카테고리라 제외. 흔한 단어는 불용어 목록 대신 문서빈도(전체 방송일의 10% 초과)로 떨어뜨린다 |
| 신의상 | 제목에 '신의상' + 평소 조회수 **2배 이상** | 예고·대기방은 0.3~1.6배, 실제 공개는 2배부터라 그 사이가 비어 있다. 3일 이내 공개는 릴레이로 묶는다. 연속일 기준 없음 |
| 생일 | `config.BIRTHDAYS`(공식 프로필)의 당일~다음 날에 그 멤버가 방송한 해 | 제목의 '생일'은 남의 생일 축하·굿즈 소개가 섞여 쓰지 않는다 |
| 콘서트 · 오리지널곡 · 3D 데뷔 · 데뷔 · 오프라인 | `data/events_manual.csv` 에 손으로 등록 | 방송 흔적이 없거나 제목으로 안전하게 못 잡는다. 같은 날 같은 종류의 자동 항목보다 수동이 우선 |

여러 신호에 걸린 이벤트는 날짜 집합의 자카드 유사도로 합친다(기간 겹침만 보면 하루짜리가 열흘짜리에 흡수된다).
넓은 창의 신호는 `data/event_candidates.csv` 검토 대기열로만 내보내고 리포트에는 쓰지 않는다.

```csv
date,end_date,type,title,members,note,source,match
2026-07-11,2026-07-12,콘서트,아카네 리제 첫 단독 콘서트,아카네 리제,,수동,
```

`members` 는 `|` 구분. 방송으로 효과를 재는 종류(합방·신의상·콘서트·생일·3D 데뷔·데뷔)는 `match` 에 방송 제목에 나오는 말을 적는다.

## 무엇을 재나

| 지표 | 측정 가능 구간 | 왜 |
|---|---|---|
| VOD 조회수 배수(이벤트 방송 ÷ 그 멤버 평소 방송) | 2025-04~ 소급 가능 | 치지직 VOD 조회수는 과거분이 남는다 |
| 치지직 팔로워 · 유튜브 구독자 전후(7일 창) | 2026-08-12~ | 일일 축적 시작일. 구독자는 1,000 단위 반올림 |
| 동시시청자 피크 배수 | 2026-08-12~ | 08 스냅샷 시작일, 소급 불가 |
| **수익** | **불가** | 치지직·유튜브 모두 비공개 |

- 수집 이전 이벤트의 전후 변화는 **계산하지 않는다** — 0% 가 아니라 측정 불가다.
- 이벤트 후 5일(`MIN_POST_DAYS`)이 지나야 전후 비교를 낸다. 이틀치로 계산하면 관측 부족이 "-100%"로 둔갑한다.
- 데뷔 방송은 데뷔 전 방송이 없어 기준선이 생길 때까지 배수가 나오지 않는다(그때까지 08 피크로 본다).
- 커버곡은 02 의 곡 단위(판 합산·음원 포함)로, 오리지널곡은 MV + 발매일 ±3일 Topic 음원으로 잰다. 같은 기간·성숙(14일 지난)
  영상만 비교해 누적 시간이 아니라 효과를 재게 한다.
- 이벤트 외에 **15개 렌즈**(커버·오리지널·콘서트·키리누키·댓글·커머스·DART·경쟁사·게임·채널·방송 패턴·시장 등)를
  같은 자로 놓는다. `REPORT.md` 맨 앞 "한눈에" 표가 전체 요약이다.

## 읽는 법 · 한계

- 평소 요인(카테고리·시간대·요일)을 바꿔 얻는 배수는 한 자릿수 초반, 신의상·데뷔 같은 이벤트는 자릿수가 다르다.
  유튜브를 움직이는 것(곡)과 치지직을 움직이는 것(신의상·데뷔)이 갈리고, 키리누키만 기획할 수 없다.
- 조회수 배수는 누적이라 오래된 이벤트가 유리하다 — 같은 시기끼리 비교한다. *(진행 중)* 표시는 아직 쌓이는 중.
- 자동 감지는 치지직 방송이 있어야 한다. 준비·리액션 방송(설명회·클립 월드컵)은 연속일 기준에서 자동으로 빠진다.
- 모든 배수·상관·건수는 실행마다 다시 계산되므로 값은 `REPORT.md` 를 본다.
