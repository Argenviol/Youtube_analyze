# 프로젝트 7 · 버추얼 크리에이터 시장 분석

글로벌 VTuber 시장 규모, 한국 스트리밍 생태계(치지직), StelLive의 시장 포지션을
**Claude 웹서치**로 수집한 공개 통계와 **프로젝트1·6에서 만든 자체 데이터**를 결합해 분석합니다.
다른 프로젝트와 달리 API 원천 수집이 아니라 **출처가 명시된 시장 리서치**가 데이터 원천입니다.

## 실행 방법

```bash
pip install -r ../requirements.txt   # API 키 불필요
python analyze.py       # data/*.csv(수동 정리된 시장 통계) -> SQL/차트/리포트/사이트 데이터
python build_site.py    # site/index.html
```

`data/market_facts.csv`·`data/stellive_milestones.csv`는 Claude가 웹서치로 조사해 정리한
구조화 데이터입니다(각 행에 출처명·URL 포함). 새로 조사한 내용으로 갱신한 뒤 `analyze.py`를
다시 실행하면 차트·SQL·사이트가 함께 갱신됩니다.

## 핵심 요약

- 글로벌 VTuber 시장: **2026년 약 31~33억 달러**, 2031~2032년 49~82억 달러로 성장 전망(CAGR 9.6~16.3%).
- 매출 구조: 구독+후원이 52.7%로 광고보다 우위 — **팬 직접 후원 기반 수익모델**이 핵심.
- 한국은 트위치 철수 이후 **치지직 독주 체제**(MAU 242만, YoY +17%) — e스포츠 중계권으로 팬층 흡수 중.
- StelLive는 2025년 7월 **브레이브 그룹(Brave Group)에 인수합병**, 12월 첫 콘서트로
  국내 인디 기획사에서 해외 자본이 결합된 성장기 그룹으로 전환.
- 프로젝트6 데이터 재확인: 규모는 작지만 **도달 효율(60%)** 이 홀로라이브·이세계아이돌 대비 압도적 —
  글로벌 성장 흐름(구독/후원 중심 수익모델)과 StelLive의 "밀도 높은 팬덤" 강점이 부합.

> 시장 규모 추정치는 리서치사별 편차가 크므로 절대 수치보다 **성장 추세·구조적 신호**로 해석하시기 바랍니다.
