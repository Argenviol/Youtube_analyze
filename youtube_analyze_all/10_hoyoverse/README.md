# 10 · 게임 캐릭터 인기도 (호요버스 4 + 블루 아카이브)

**질문** — 게임사가 미는 캐릭터와 유저가 실제로 이야기하는 캐릭터는 일치하는가.

- 대상: 원신 · 붕괴:스타레일 · 젠레스 존 제로 · 붕괴3rd(호요버스) · 블루 아카이브(넥슨). **게임마다 따로** 분석한다
- 데이터: 캐릭터 마스터 + 한국어 유저 반응 코퍼스(아래). 캐릭터 이름은 한국 서버 표기
- 갱신: weekly. 스텔라이브 프로젝트와 도메인이 달라 **게임 리포트**로 따로 낸다

## 실행

```bash
export YOUTUBE_API_KEY=...        # 공식 채널 댓글용. 나머지 소스는 키 불필요
python collect.py --days 365      # 캐릭터 마스터 + 수집 시점부터 365일 창의 반응 코퍼스 → data/
python analyze.py
python build_site.py
```

## 데이터 소스

| 구분 | 소스 | 비고 |
|---|---|---|
| 캐릭터 마스터 | 원신·스타레일: `yatta.moe` · 젠존제: Enka.Network 공개 저장소 + Fandom 위키 출시일 · 붕괴3rd: Fandom 위키 전투복/버전 + `data/hi3_names_ko.csv`(**한글 이름은 수동 표**) · 블루 아카이브: SchaleDB 공개 데이터 | 빠진 조각은 빈 값으로 둔다(`sources.py`) |
| 유저 반응 | Google Play 리뷰(KR) · Apple App Store 리뷰(KR, 앱당 최대 500건) · 공식 한국 유튜브 채널 댓글 · HoYoLAB 한국어 글 댓글(호요버스만) | 시험해서 되는 것만. 안 되는 소스(아카라이브·디시·레딧 등)와 이유는 `data/source_probe.json` |
| 안 쓰는 것 | Google Trends(`pytrends` 매 호출 429) · Enka 쇼케이스 UID(표본 편향·문서가 열거 금지) | `data/trends_status.json` 에 실패를 그대로 기록 |

기간은 다섯 게임 모두 **수집 시점부터 365일**로 같다(건수가 아니라 기간을 맞춘다). 리뷰·댓글은 덮어쓰지 않고 누적하며
유튜브 댓글은 최근 21일 영상과 처음 보는 영상만 다시 받는다(`COMMENT_REFRESH_DAYS`).

## 지표 정의

| 지표 | 정의 |
|---|---|
| 공식 푸시 순위 `push_rank` | 최고 등급(5성·S급) 캐릭터만, 출시 최신순. 배너 이력 API 가 없어 "가장 최근에 민 것"의 프록시. 붕괴3rd 는 가장 최근 S급 전투복 출시일 |
| 유저 반응 순위 `audience_rank` | 리뷰·댓글 본문의 이름 언급 횟수. 게임 안에서만 매긴다 |
| 격차 `gap` | `audience_rank − push_rank` — 양수면 밀었는데 반응이 약함, 음수면 숨은 인기 |
| 감성 | 언급 리뷰 평균 평점 − 게임 전체 평균 |

게임끼리 비교할 때는 **공통 표본(플레이+애플+유튜브)의 만 건당 언급**만 쓴다(HoYoLAB 은 블루 아카이브에 없음).
여행자·개척자처럼 가챠 대상이 아닌 플레이어 아바타는 제외.

## 읽는 법 · 한계

- 다섯 게임 모두 **공식 푸시 1위와 가장 많이 언급되는 캐릭터가 다르다.** 반응 상위에는 출시가 오래된 캐릭터가 꾸준히
  올라온다. 캐릭터 이름·건수는 `REPORT.md` 게임별 요약.
- **언급량은 인기가 아니라 화제성이다.** 리뷰는 불만을 쓰러 오는 곳이기도 하다. 어떤 소스에도 안 나오는 캐릭터가 게임마다
  있고 그 비율은 게임마다 크게 다르다 — 언급 0 은 표본이 닿지 않은 것이지 비인기가 아니다.
- 이름 매칭은 부분 문자열이라 1글자 이름은 매칭하지 않고, 2글자 이름은 상한값으로 읽는다(배지 표시).
- 리뷰가 두 자릿수인 게임은 언급 순위가 사실상 서지 않는다 — 그것도 결과로 적는다(`SMALL_SAMPLE`).
- 인과 문장("배너를 돌려서 언급이 늘었다")은 쓰지 않는다. 관찰만 보고한다.
- `yatta.moe` 페이지에는 코드 에이전트에게 숨은 지시를 주는 `<meta name="agents">` 가 있었다. 페이지 콘텐츠일 뿐이라
  따르지 않았고 공개 REST 엔드포인트만 호출했다.
