# 프로젝트 11 · 팬 커머스 분석

**"팬덤은 얼마를 쓰고, 그 돈은 회사에 남는가?"** 를 세 레이어로 쪼개서 본다 —
가격 구조(팬딩) · 실제 지출(텀블벅) · 회사에 남는 것(DART 감사보고서, 09 재사용).
세 레이어는 확보 방법이 근본적으로 다르고, 그 차이 자체가 이 프로젝트의 발견이다.

## 실행 방법

```bash
pip install -r ../requirements.txt   # API 키 불필요(전부 공개 페이지·재사용 데이터)
python collect.py                    # 팬딩 REST 수집 + 텀블벅 정적 큐레이션 + 09 재사용 -> data/
python analyze.py                    # 지표 산출 -> SQL/차트/리포트/사이트 데이터
python build_site.py                 # site/index.html
```

## 세 레이어와 그 확보 방식

### 레이어 1 · 가격 구조 (팬딩) — 자동 수집 성공

팬딩(Fanding) VTuber 카테고리 크리에이터 전원(111명)의 공개 멤버십 페이지
(`/en/@{creator}/membership`, 로그인 불필요)을 순회해 티어명·가격을 수집했다.

- `robots.txt`(`https://fanding.kr/robots.txt`) 확인 결과 `/studio/*`(크리에이터 관리자
  화면)·`/app-map`·`/account-info`·`/payment-return` 등 관리·결제 영역만 막혀 있고,
  크리에이터 목록 REST(`/rest/explorer/creator_list`)와 멤버십 페이지는 포함되지 않는다 —
  수집 진행.
- 멤버십 페이지는 Nuxt 서버 사이드 렌더링이라 `window.__NUXT__`에 티어 데이터가 그대로
  박혀 있다. 다만 Nuxt의 devalue 직렬화는 반복되는 공유값을 문자 변수로 치환해서
  전체를 `json.loads`로 파싱할 수 없다 — 대신 `title`(고유 문자열)과 `price`(고유 정수)는
  치환 대상이 아니라는 걸 여러 크리에이터 페이지에서 직접 확인했고, 그 순서
  (`title → operationType → renewable → price`)도 고정돼 있어 정규식으로 안전하게 뽑는다.
- 결과: 크리에이터 111명 중 **57명이 유료 티어를 운영**, 총 **67개 티어**,
  가격 범위 1,000원~550,000원(중앙값 7,200원). 스텔라이브 공식 팬클럽(파스텔) 6기는
  24,000원/월로 하위 84%ile 구간(더 저렴한 티어가 84% 있다는 뜻) — 중앙값보다는 높지만
  최고가 구간은 아니다.

⚠ **가격 ≠ 매출.** 팬딩은 구독자 수를 공개하지 않는다. 이 레이어는 "팬이 얼마를
요구받는가"만 다루고 실제 수입은 추정하지 않는다.

### 레이어 2 · 실제 지출 (텀블벅) — robots.txt에 막혀 자동 수집 불가, 정적 큐레이션으로 대체

**가장 강한 근거가 될 예정이었지만, 자동 수집이 불가능하다는 게 이 레이어의 첫 번째
발견이다.** 텀블벅 프로젝트 상세 페이지(`tumblbug.com/{slug}`)는 클라이언트 렌더링
SPA라서 정적 HTML에는 모금액·후원자 수·달성률이 없다 — React 앱이 뜬 뒤
`GET /api/v3/project/{slug}/detail` 등을 호출해야 채워진다(브라우저 네트워크 탭으로
직접 확인). 그런데 텀블벅 `robots.txt`(`https://tumblbug.com/robots.txt`)는
**`Disallow: /api/`** 를 명시한다. 즉 이 프로젝트가 원하는 수치의 유일한 출처가
로봇배제표준으로 막혀 있다.

- `collect.py`는 `requests`만 쓰고 JS를 실행하지 않으므로 애초에 `/api/`를 호출하지
  않는다(빈 껍데기 HTML만 받는다) — robots.txt를 어기려야 어길 수가 없는 구조다.
- 헤드리스 브라우저로 렌더링해 우회하는 방법도 검토했지만, 그건 매 실행마다 동일한
  `/api/` 엔드포인트를 반복 호출하는 것과 다르지 않아 규칙의 취지를 어기게 된다 —
  채택하지 않았다.
- 와디즈(Wadiz)는 `robots.txt`가 개별 캠페인 페이지(`/web/campaign/detail/*`)를 막지
  않아 기술적으로는 더 우호적이지만, 검색으로는 VTuber 카테고리 캠페인을 사실상 찾지
  못했다 — 국내 버튜버 크라우드펀딩 수요가 텀블벅에 쏠려 있는 것으로 보인다. 그래서
  이 프로젝트는 와디즈를 다루지 않는다.

**대안**: 이미 공개적으로 발표된 결과 — ① 텀블벅 자체 발표·언론 보도가 사후 집계한
최종 수치(공식 굿즈 펀딩 2건), ② 프로젝트 상세 페이지를 2026-08-12에 1회성으로 직접
열람해 확인한 수치(팬메이드 광고 펀딩 4건) — 를 출처(`source_url`, `source_type`)와
함께 `CROWDFUNDING_PROJECTS`(정적 리스트, `collect.py`)에 큐레이션했다.
**이 레이어는 재실행해도 갱신되지 않는다** — 라이브 API가 아니기 때문이며, `data/_meta.json`의
`tumblbug_blocked_by_robots`에 이유를 그대로 남긴다.

표본에 없다 — 달성률 분포는 실제보다 낙관적으로 왜곡돼 있을 가능성이 크다.

⚠ **팬메이드 광고 펀딩은 회사 매출이 아니다.** '유니버스 데뷔 3주년 기념 광고' 창작자는
텀블벅 프로젝트 업데이트 게시물에서 최종 정산액 34,114,780원(플랫폼 수수료 약 9.9% 차감
후)을 전액 광고비·일러스트레이터 외주비로 지출했다고 상세 내역과 함께 직접 공개했다 —
이 돈은 스텔라이브 회사 매출로 잡히지 않고 팬 커뮤니티 내부에서 돌 뿐이다. "팬덤이 쓴 돈"
전부가 회사로 흘러간다고 가정하면 안 된다는 걸 보여주는 사례로 그대로 남겼다.

### 레이어 3 · 회사에 남는 것 (09_dart_financials 재사용) — DART 재수집 없음

`09_dart_financials/data/company_metrics.csv`를 읽기 전용으로 재사용한다
(패러블엔터테인먼트·샌드박스네트워크). PRD 지시사항대로 DART를 다시 호출하지 않는다.
**팬딩(Fanding)은 09에서 이미 확인했듯 DART 공시가 1999년부터 전체 기간을 조회해도
0건이다** — 감사보고서조차 제출한 적이 없는 법인이라 이 레이어에 팬딩 자체의 재무는
없다. 이 프로젝트가 다시 확인하지 않는다(PRD의 "이미 확정된 제약" 그대로 계승).

- **패러블엔터테인먼트**(이세계아이돌 소속사, 언론 보도 기준): 매출 2024년 209.5억원 →
  2025년 218.3억원(+4.2%)으로 증가했지만, 영업이익은 2024년 +12.1억원(흑자)에서
  2025년 -91.0억원(적자)으로 전환됐다.
- **샌드박스네트워크**: 2018~2025년 **8개 연도 전부 영업손실**. 2025년 매출 731.5억원에도
  영업이익률 -5.8%. 2023~2025년은 연결기준 자본총계가 음수(완전자본잠식).

## 세 레이어를 나란히 놓아보면 (관찰 — 증명 아님)

이세계아이돌 굿즈 펀딩 두 건은 41억원·88억원이라는 국내 크라우드펀딩 역대 최고 기록을
냈다. 같은 기간 그 IP의 실제 관리사로 보도된 패러블엔터테인먼트의 감사보고서는 매출이
늘었는데도 영업이익은 흑자에서 대규모 적자로 무너졌다. 팬덤이 쓰는 돈이 늘어난다고
회사에 남는 돈이 늘어난다는 보장은 없다 — 샌드박스네트워크는 관측된 8개 연도 내내
영업손실을 기록했다.

⚠ **이건 증명이 아니라 관찰이다.**
1. 크라우드펀딩 프로젝트의 IP 소유자(이세계아이돌)와 감사보고서 법인(패러블엔터테인먼트)은
   "실제 관리사"라는 언론 보도로만 연결돼 있어, 이 펀딩 수익이 그 재무제표에 정확히 얼마나
   반영되는지는 알 수 없다(굿즈 원가·제작·유통사 몫이 따로 있을 수 있다).
2. 재무 표본이 회사 2곳 × 몇 개 연도뿐이라 **상관계수를 계산하지 않았다.**
3. 회계연도(연 1회 갱신)와 크라우드펀딩 캠페인(특정 시점)은 기간이 정확히 겹치지 않는다.
4. 팬딩 가격 레이어는 이 두 회사와 아예 무관한 제3의 플랫폼 데이터라 세 레이어를 하나의
   숫자로 합칠 수 없다 — 그래서 세 레이어를 병렬로만 제시하고 억지로 잇지 않았다.

## 지표 정의

- **팬딩 가격 통계** — 크리에이터별 평균가는 해당 크리에이터가 운영하는 모든 티어 가격의
  단순 평균. 전체 분포(최소·중앙값·평균·최대)는 67개 티어 전체 기준.
- **크라우드펀딩 달성률** = 모인금액 / 목표금액 × 100. **1인당 평균 후원액** = 모인금액 / 후원자 수
  (실제 결제 분포는 알 수 없다 — 평균일 뿐, 소수의 고액 후원이 평균을 끌어올렸을 수 있다).
- **영업이익·영업이익률** — 09_dart_financials의 정의를 그대로 따른다(연결 우선, 없으면 별도).
