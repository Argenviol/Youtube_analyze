## 팬덤 밀도 (팔로워 1천명당 동시시청자)

## 유닛별 팔로워 증감 합계

```sql
SELECT unit AS 유닛, COUNT(*) AS 인원, SUM(follower_delta) AS 증감합계
FROM member_metrics GROUP BY unit ORDER BY 증감합계 DESC;
```
