# collect — 정보를 모으는 곳

새로 들어오는 원천 자료만 둔다. 분석은 [`../analysis/`](../analysis/)에서 이 폴더의 `data/` 를 읽는다.
기존 01~08·12 프로젝트는 자기 폴더에서 수집·분석을 같이 하며 그대로 둔다.

| 스크립트 | 모으는 것 | 산출 | 키 |
|---|---|---|---|
| `chzzk_chat.py` | 치지직 다시보기 채팅 — 분당 채팅·후원 건수·구독 메시지·채팅 참여자 해시 | `data/chat_minutes.csv` · `chat_videos.csv` · `chatters/` | 불필요 |
| `anime_season.py` | 다음 분기 TV 애니 일정(AniList) | `data/anime_season.csv` | 불필요 |

## 못 모으는 것
- 후원 **금액** — 다시보기 채팅의 `payAmount` 는 항상 0.
- 눈팅 시청자, 시청자 유입 경로 — 치지직이 공개하지 않는다.
- 닉네임·채팅 본문은 일부러 저장하지 않는다(익명 해시만).
