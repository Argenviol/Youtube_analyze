# 프로젝트 6 · 경쟁사 비교 분석

**StelLive vs 홀로라이브(Hololive) vs 이세계아이돌(이세돌)** — 각 그룹 대표 멤버 6명 표본으로
구독자·조회수·참여율·업로드빈도·도달효율을 비교합니다.

## 실행 방법

```bash
pip install -r ../requirements.txt
export YOUTUBE_API_KEY="발급받은_키"

python collect.py --recent 30    # 3그룹 18채널 -> data/
python analyze.py                # SQL/차트/리포트/사이트 데이터
python build_site.py             # site/index.html
```

## 비교 대상

| 그룹 | 대표 멤버 6명 |
|------|--------------|
| StelLive | 아야츠노 유니·사키하네 후야·시라유키 히나·네네코 마시로·아카네 리제·아라하시 타비 (창립자 강지 제외 탤런트 상위 6명) |
| 홀로라이브 | 우사다 페코라·가우르 구라·호쇼 마린·모리 캘리오프·모모스즈 네네·이누가미 코로네 (JP/EN 혼합 대표) |
| 이세계아이돌 | 아이네·징버거·릴파·주르르·고세구·비챤 (왁타버스, 전원) |

모든 채널 ID는 YouTube Data API로 검증했습니다(`common/config.py`의 `COMPETITORS`).

## 주요 결과 (수집 시점 스냅샷)

| 지표 | StelLive | 홀로라이브 | 이세계아이돌 |
|------|---------:|----------:|-------------:|
| 평균 구독자 | 264K | 3.00M | 414K |
| 평균 최근 조회수 | 156K | 482K | 94K |
| 평균 참여율 | 4.2% | 7.0% | 6.2% |
| 주간 업로드 | 3.8회 | 4.2회 | 4.7회 |
| 도달 효율 | 60% | 14% | 23% |

- **규모**: 홀로라이브(글로벌) ≫ 이세계아이돌(국내 대형) > StelLive(신생/중견) — 시장 포지션이 뚜렷.
- **도달 효율**은 정반대로 StelLive가 압도적 1위 — 규모가 작을수록 구독자 대비 실제 조회수 비율이
  높은, "소규모지만 응집력 있는 팬덤" 구조를 보여줌.
- 참여율은 홀로라이브가 가장 높지만(7.0%), 이는 조회수 자체가 커서 좋아요·댓글 절대량도 크기 때문 —
  절대 규모와 상대 효율은 다른 지표임에 유의.

> 표본 주의: 각 그룹 6명 대표 비교이며 전체 소속 인원(홀로라이브 수십 명 등) 비교가 아닙니다.
