# StelLive 팬덤 애널리틱스

버추얼 크리에이터 그룹 **스텔라이브**를 중심으로, 공개 데이터만으로 팬덤 지표와 실제
재무 성과를 연결해 본 데이터 분석 포트폴리오입니다.

설문이나 비공개 데이터 없이 **이미 공개된 지표만** 사용하며, 11개 프로젝트 모두
`수집 → 정제 → SQL → 시각화 → 대시보드`의 같은 파이프라인을 따릅니다.

```
youtube_analyze_all/   분석 파이프라인 11개 (Python · pandas · SQLite · matplotlib)
app/                   통합 대시보드 (Next.js · TypeScript · 정적 export)
.github/workflows/     자동 수집 (live 10분 / daily / weekly / monthly)
PRD.md                 요구사항 정의서
```

## 무엇을 발견했는가

- **팔로워 규모 1위와 팬덤 밀도 1위는 다른 사람이다.** 구독자 상위 멤버와 영상당
  참여율 상위 멤버가 겹치지 않는다.
- **플랫폼마다 성장 곡선이 다르다.** 유튜브 구독자 증가 최하위권인 멤버가 치지직
  팔로워 증가에서는 1위였다.
- **팬은 돈을 쓰지만 회사에 남지는 않는다.** 팬딩 월 구독 중앙값은 7,200원인데
  크라우드펀딩 1인당 후원액은 24.8만원(약 34배)이다. 그런데 같은 IP를 운영하는
  패러블엔터테인먼트의 감사받은 FY2025 영업이익은 −91억원이고, 샌드박스네트워크는
  2018년 이후 8년 내내 영업적자다.

## 이 저장소에서 봐야 할 것

분석 결과보다 **[방법론 페이지](app/src/app/methodology/page.tsx)** 를 먼저 보시길
권합니다. 작업 중 실제로 발견한 데이터 함정 9건을 무엇이 있었나 / 어떻게 발견했나 /
어떻게 처리했나로 기록했습니다. 몇 가지 예:

- **치지직은 방송이 꺼져 있어도 직전 방송의 동시시청자 수를 돌려준다.** 첫 수집에서
  11채널 전부 오프라인인데 1,600~3,800명으로 찍혔다. 그대로 쌓았다면 오프라인 구간이
  "시청자가 계속 있는 평지"로 그려졌을 것이다.
- **커버곡 수집이 재현되지 않았다.** `search.list` 상위 40개 창만 보고 있어서 같은
  코드·같은 채널인데 실행 시점에 따라 결과가 달라졌다. 업로드 재생목록 전량 열거로
  교체하니 결정적이 되었고 쿼터도 3,300 → 173 units로 줄었다.
- **커버리지를 달력 시간으로 재고 있었다.** PC를 하루 꺼두면 `span`은 24시간을 넘지만
  실제 데이터는 몇 시간치뿐이다. "얇은 데이터로 만든 그럴듯한 차트"를 막으려던 가드가
  정확히 그 상황에서 무력해지는 구조였다.

## 실행

```bash
pip install -r youtube_analyze_all/requirements.txt
cd app && npm install
```

API 키는 환경변수로만 씁니다 (발급 절차는
[`SETUP_KEYS.md`](youtube_analyze_all/SETUP_KEYS.md)).

```bash
python youtube_analyze_all/scripts/refresh.py --group daily   # 수집 → 분석 → 사이트
cd app && npm run build                                       # 정적 대시보드 빌드
```

⚠ 빌드 결과물은 에셋을 `/_next/...` 절대경로로 참조합니다. **`file://` 로 열면 아무것도
로드되지 않으니** HTTP 로 서빙해야 합니다.

## 데이터에 대한 태도

- 수집 방식이 바뀌면 `_meta.json`에 `method_changed_at`을 남기고, 그 경계를 넘는 비교는
  하지 않습니다.
- 표본이 편향된 소스는 채택하지 않습니다 (Enka.Network — 쇼케이스 공개 유저만 잡히고
  공식 문서가 UID 열거를 금지).
- `robots.txt`가 막는 경로는 우회하지 않습니다 (텀블벅 — 수집 불가를 기록하고 출처를
  명시한 정적 데이터로 대체).
- 데이터가 부족하면 결론을 내지 않습니다 (FR-5 커버리지 가드).

디자인 토큰은 [Montage](https://github.com/wanteddev/montage-web) (Wanted Lab, MIT)의
값을 사용했습니다. 패키지가 GitHub Packages 전용이라 토큰 값만 이식했습니다.
