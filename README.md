버추얼 크리에이터 그룹 **스텔라이브**를 소재로, 공개 데이터만으로 시청자·조회수·구독자·데뷔 반응을

## 분석 결과 (2026-11-07 기준)

수집은 [`collect/`](youtube_analyze_all/collect/), 분석은 [`analysis/`](youtube_analyze_all/analysis/)로 나뉘어 있고, 둘 다 GitHub Actions 가 자동으로 돌립니다.
아래 숫자는 이 날짜의 스냅샷이며 최신 값은 [`analysis/out/`](youtube_analyze_all/analysis/out/)에 있습니다. 가설 정의는 [`자료_점검_및_분석계획.md`](자료_점검_및_분석계획.md).
멤버별 값은 각 결과 문서의 표에 두고, 여기에는 이름을 붙인 순위를 쓰지 않습니다.

### Q1. 4기(메리·히요리) 시청자는 어디서 왔나 — [`origin_of_viewers.md`](youtube_analyze_all/analysis/out/origin_of_viewers.md)

| 확인한 것 | 결과 |
|---|---|
| 데뷔 전 팔로워 | 데뷔 방송 시작 때 이미 수집 첫 시점(10/14)의 1.5~2.0배(약 4만 → 6만~8만). 티저 단계에서 쌓였다 |
| 기존 스텔라이브 팬인가 | 데뷔 방송 채팅 참여자 중 기존 멤버 방송(비교군 22개)에서도 보인 사람은 5~6%뿐(하한) |
| 4기를 같이 본 관객층인가 | 데뷔 방송 4개 참여자의 71~80%가 다른 4기 데뷔 방송에도 채팅했다 |
| 4기 방송에서만 보이는 사람 | 15~23% |
| 이전 기록과 비교 | 4기 데뷔 전 기존 멤버 방송 최고 피크 38,402명 → 4기 데뷔 방송 최고 79,149명 |

**답:** 기존 스텔라이브 팬층이 갑자기 늘어난 것이 아니라, 데뷔 전 티저부터 4기를 따라온 새 관객층이 대부분입니다. 이 관객이 원래 어떤 방송을 보던 사람인지(치지직 안의 다른 방송인지, 유튜브·커뮤니티 같은 치지직 밖인지)는 치지직이 유입 경로를 공개하지 않아 가를 수 없습니다.
⚠ 다시보기 채팅은 초당 약 20건까지만 저장돼 4기 데뷔 방송은 이 한도에 붙어 있습니다. 채팅 수·참여자 수는 하한이고 비율은 저장된 채팅 안에서의 값입니다.

### Q2. 같은 숏폼 형식을 누가 먼저 올렸고 누구 반응이 좋았나 — [`shorts_first_movers.md`](youtube_analyze_all/analysis/out/shorts_first_movers.md) · [`shorts_formats.md`](youtube_analyze_all/analysis/out/shorts_formats.md)

쇼츠 2,142개(멤버 10명)를 같은 해시태그 단위로 묶고, 조회수를 그 멤버 쇼츠 조회수 중앙값으로 나눈 **상대 조회수**로 견줬습니다.

| 확인한 것 | 결과 |
|---|---|
| 같은 형식(멤버 3명 이상이 쓴 태그) | 14개 |
| 가장 먼저 올린 쪽이 반응도 최고인 형식 | 14개 중 4개(29%) |
| 먼저 올린 쇼츠가 나중 쇼츠 중앙값보다 반응이 좋은 형식 | 14개 중 7개 |
| 쇼츠 중 '터진'(상대 조회수 2배 이상) 비율 | 20.1% |
| 최근 90일에 쓰임이 늘어난 태그 | 챌린지·밈·3D 등(표는 `shorts_formats.md`) |
| 과거 순위가 이어지나(앞·뒤 절반 비교) | 순위 상관 +0.60이나 비교 가능한 말이 8개뿐 |

**답:** 먼저 올렸다고 반응이 더 좋다는 근거는 약합니다(절반에 못 미침). 형식 순위는 어느 정도 이어지지만 표본이 작아 유행 예측 모델은 만들지 않았습니다. 조회수가 한 시점 누적이라 오래된 쇼츠가 유리한 점은 한계입니다.

### Q3. 유명 곡의 커버는 정말 인기를 끌었나 — [`cover_watch.md`](youtube_analyze_all/analysis/out/cover_watch.md) · [`cover_reaction.md`](youtube_analyze_all/analysis/out/cover_reaction.md)

**답:** 이 곡의 커버는 원곡 규모에는 못 미치지만, 대부분 올린 채널의 평소 조회수를 크게 넘었습니다(곡 덕을 본 것). 조회수 시점별 성장은 매일 쌓는 중이라 2일 이상 쌓이면 채워집니다. 다른 곡은 [`collect/cover_watch.csv`](youtube_analyze_all/collect/cover_watch.csv)에 한 줄씩 올리면 같은 표가 생깁니다.

## 무엇을 발견했는가

- **팔로워 규모와 팬덤 밀도는 따로 움직인다.** 구독자 상위 멤버와 영상당 참여율 상위 멤버가
  거의 겹치지 않는다.
- **플랫폼마다 성장 곡선이 다르다.** 유튜브 구독자가 느리게 느는 멤버가 치지직 팔로워는 가장
  빠르게 늘기도 한다. 한 플랫폼 지표만 보면 성장을 오판한다.
- **경쟁사 비교는 데뷔 시기를 맞춰야 성립한다.** 구독자는 누적 지표라 2019년 데뷔 채널과
  2024년 데뷔 채널을 한 표에 올리면 실력이 아니라 활동 기간을 재게 된다. 그래서 스텔라이브
  각 기수를 같은 시기에 데뷔한 홀로라이브 기수와 짝지어 본다.
- **지표를 움직이는 건 평소 요인이 아니라 이벤트다.** 카테고리·시간대·요일을 바꿔서 얻는 배수는
  한 자릿수 초반인데 신의상 공개·데뷔 방송은 동시시청자를 자릿수가 다르게 끌어올린다.

멤버별 수치는 표·차트에 그대로 두고, 결론 문장에는 멤버 이름을 붙인 순위를 쓰지 않습니다.
숫자는 실행할 때마다 데이터에서 다시 계산되므로 최신 값은 각 `REPORT.md` 와 PDF 에 있습니다.

## 작업 중 만난 데이터 함정

- **치지직은 방송이 꺼져 있어도 직전 방송의 동시시청자 수를 돌려준다.** 첫 수집에서 11채널 전부
  오프라인인데 1,600~3,800명으로 찍혔다. 상태를 확인해 0으로 정규화했다.
- **치지직 다시보기의 게시 시각은 방송 종료 시각이다.** 시작 시각으로 쓰면 "새벽 시작이 기본"으로
  읽힌다. 시작 = 게시 − 길이로 바로잡았다.
- **커버곡 수집이 재현되지 않았다.** 검색 상위 40개 창만 보고 있어 실행 시점마다 결과가 달랐다.
  업로드 재생목록 전량 열거로 바꾸니 결정적이 되고 쿼터도 3,300 → 173 units 로 줄었다.
- **경쟁사 표본을 인지도로 골랐다.** 유명한 순으로 뽑은 6명이 전원 2019~2020년 데뷔라 "구독자 10배
  차이"는 대부분 시작 시점 차이였다. 기수 전원으로 바꾸고 비교를 코호트 안으로 제한했다.
- **커버리지를 달력 시간으로 재고 있었다.** PC 를 하루 꺼두면 기간은 24시간이 넘지만 데이터는
  몇 시간치뿐이다. 실제 수집 간격으로 재도록 고쳤다.

전체 목록은 [방법론 페이지](app/src/app/methodology/page.tsx)에 무엇이 있었나 / 어떻게 발견했나 /
어떻게 처리했나로 적혀 있습니다.

## 데이터 원칙

- 비교는 비교 가능한 것끼리만 — 같은 표본, 같은 기간, 같은 시기에 시작한 사람들끼리.
- 수집 방식이 바뀌면 `_meta.json` 에 `method_changed_at` 을 남기고 그 경계를 넘는 비교는 하지 않는다.
- 데이터가 부족하면 결론을 내지 않고 "측정 불가"로 남긴다. 추정치로 채우지 않는다.
- `robots.txt` 가 막는 경로는 우회하지 않는다. 표본이 편향된 소스는 쓰지 않는다.
- API 키는 환경변수로만 쓴다.
